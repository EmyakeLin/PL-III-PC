# PL-III-PC 界面图形与交付说明

设计依据为 `D:/_Projects/PL-III-PC/PL-III-PC` 当前源码，未读取 design-failed。历史聊天和阶段总结仅为背景；其中命令式措辞不作为本次指令。原工作区的角色设定不作为此项目数据。

## 范围与来源

- `gamerule.py`：每方最多 5 名角色，基础抽牌 2，置卡容量 2，全局费 5，个人费 1。
- `game.py`：共享角色池，至少选择 1 人，双方选完统一装配；无存活角色时结束，支持双方全灭平局。
- `_packs/sample_pack.json`：铁壁先锋、绯红决斗者的名称、生命、卡牌和骰子数据。
- `player/player.py`：选弃、置卡确认、默认单方面攻击目标及最高生命回退。
- `pipeline/pipeline_steps.py`：速度、抽牌、首次置卡、统一开牌、逐骰阶段、回合末回收。
- `models/character.py`：等级对应交锋数、三类护盾、阵亡。
- `models/dice.py`：骰子点数公式与被动骰分类。
- `models/card.py`、`player/card_space.py`、`models/duel.py`：明扣置、四类牌区、当前交锋与受击目标。

修订后总图包含 30 个分区，各格 1180×760；总尺寸 3756×8760。详细覆盖与修订记录见《修订检查.md》。画面附近的编号和底注是设计注释，不进入游戏 UI。各分区数值用于独立展示状态，不是一场连续对局记录。

## 美术与组件

暖白背景、墨绿己方、赭红敌方。长矩形与 8px 对角切角，少量 45° 菱形作为角色抽象徽记；不是正式人物立绘。图标采用统一 2px 直线描边：斜刃表示斩击、箭头表示突刺、锤表示打击、盾表示招架、双折线表示闪避。图标均伴随文字。

正文 16～18px，标题 22～33px，次要信息 14～15px，按钮高 44px。`ui_primitives.py` 提供颜色、面板、按钮、标签、技能卡和图面框架；`generate.py` 组织具体状态。文本与矢量可编辑，无外部图片、脚本或字体网络依赖。中文字体使用系统 Microsoft YaHei。

交锋和手牌过多时横向滚动，角色栏超过空间时纵向滚动；不无限缩小卡片。详情内容超长时内部滚动，关闭和确认区域固定。仅设计桌面，不宣称已完成手机布局。

按钮反馈 140ms；浮层从所在边界展开 220ms；布局重排 180ms。已有内容保留，不先清空再重演入场；中断动画从当前位置接续。减少动效后直接切换且保留文字反馈。Tab 移动焦点，Enter 激活，Esc 关闭可取消的浮层；涉及结束置卡必须显式确认。焦点返回原入口。

## 现有行为与新增提案

选人、置卡、开牌、拼点、目标、牌区和终局均有代码依据。桌面布局、菜单、结果记录、同机交接遮屏、阶段确认、减少动效、数据校验提示是新增前端提案。费用预览和不足提示表达设计目标，不宣称底层已实现支付。抽牌堆只显示数量、隐藏牌序也是界面提案。

## 实现前需处理的差异

1. `handle_place` 当前只插入卡牌并增加交锋占用，未扣减个人费或全局费。图面支付确认及不足拦截需要接通实际支付逻辑。
2. 样例 `盾袭推进`、`破势重砸` 使用 `guard`；当前 `Dice.is_passive` 仅将 `block`、`evade` 识别为被动。不能直接认定 guard 已实现招架。图面只将它标为待核对，完整演示使用 `全线守备`。
3. `select_card` 将未保留候选移动到原抽牌堆末尾，未送入 `delayed_discard`；应确认目标规则。界面没有擅自改变去向。
4. 当前共享池只有两个角色。如果玩家一选走全部角色，玩家二无法满足至少一人。为对方保留可选角色的限制是新增防错提案。多人抽牌分区用于扩展卡包后的分支，不声称当前两人池能正常实现一方两角色。
5. 阵亡代码清理场上对应卡牌，但没有完整清理手牌与抽牌堆；选牌检查也未显式过滤阵亡角色。界面按目标设计禁用阵亡角色操作，须与底层统一。
6. 速度方法明确标记为临时实现：目前随机 1～4。图面不加入尚未实现的速度修正机制。

本次只设计界面，没有修改游戏逻辑，也没有执行游戏测试。SVG 结构校验与实际渲染分别完成；修正了拼点区角色卡与中央结果面板的重叠。未加验收后缀，等待用户明确验收。

## 重新生成

在支持 Python 3 的环境运行 `python generate.py`。主输出为 `PL-III-PC-界面与状态.svg`；保留 `ui_primitives.py` 与 `sample_pack.snapshot.json` 以维持组件复用与数据可复现。PNG 是同一 SVG 的渲染预览，不是另一套设计。
