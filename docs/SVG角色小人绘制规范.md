# SVG 角色小人绘制与骨骼接入规范（《光点计划 III》）

## 1. 美术定位：小巧简洁的日光几何棋子 / 徽章人偶（Compact Minimalist Figurine）

为了在 **1v1 对决**、**10v10 多排编队** 和 **换阵容图鉴** 中都保持极高辨识度与统一美感，角色小人坚持**「小巧、简洁、明亮、零杂乱层级」**原则：

- **紧凑 1:1 徽章剪影**：标准画布 `viewBox="0 0 160 160"`，底座锚点 `data-foot="80,140"`，整体高度紧凑，直接稳坐于战场地面光环之上，不画冗余细腿与臃肿肢体。
- **明亮轻盈的线条语言**：
  - 披风、风带与光环以**无硬黑边的半透明水彩色块**绘制；
  - 躯干使用**暖白描边 `#FFFDF7`** 衬托鲜明主色；
  - 头部为简洁温润的**象牙白圆/六边形胚体**，搭配 **1 个核心标志性头饰/护目镜/冠饰**（不画繁复具象五官）；
  - 前景武器采用**暖白刃面 + 角色主色刃边 + 金属/副色中脊**，一眼可辨。
- **零纯黑、零霓虹蓝紫**：深色描边统一用暖炭棕 `#3B322A`，严格契合明亮纸本棋盘调性。

## 2. 标准画布与 5 核心骨骼分层（兼容自定义扩展）

- **画布尺寸**：`viewBox="0 0 160 160"`
- **底座站立锚点**：`data-foot="80,136"`（底座稳固贴合战场地面光环，呼吸采用底部锚定弹性伸缩，永不浮空或穿模）
- **标准朝向**：统一**面朝右侧（+X）**；左侧玩家一保持 `scale.x = +1`，右侧玩家二自动镜像 `scale.x = -1`。
- **防溢出裁切规范（`<clipPath>`）**：
  - 躯干内部装饰（斜挎带、拼色衣摆、护胸甲、金缮裂纹）须包裹在躯干 `<clipPath>` 内，最后叠加连续无断点的外描边。
  - 头部护目镜、面罩与头带须包裹在头部 `<clipPath>` 内，确保完美贴合圆形/六边形轮廓边缘，绝不突兀出框。
  - 前景武器统一置于前侧外沿（`x >= 94`），不横切胸口纹章。

前端引擎（[svg_rig.js](../battle_ui/static/engine/svg_rig.js)）按 SVG 文档顺序解析所有 `<g id="bone_*">` 分组，首次加载时 2.5× 超采样缓存为 GPU 纹理，并以**层级联动骨骼运动**（`bone_head`、`bone_cape_back`、`bone_weapon` 跟随 `bone_torso` 底座倾角联动）驱动 60fps 呼吸、突进与受击动画：

| 骨骼分组 ID | 默认旋转中心 `data-pivot` | 职责与动态行为 |
|---|---|---|
| `bone_back_hair` | `80,86` | 背后日光光环 / 阵营徽章 / 星盘 / 火花 |
| `bone_cape_back` | `70,82` | 背后风带 / 围巾 / 战旗披风（紧贴肩后，突进时联动后扬） |
| `bone_arm_back` *(可选)* | `96,98` | 副手道具（如盾牌、星盘、青铜铃等） |
| `bone_torso` | `80,136` | 底座锚定的棋子主躯干与肩甲/斜挎带/腰封（底部弹性呼吸） |
| `bone_head` | `80,68` | 象牙白头胚 + `<clipPath>` 贴合护目镜/头带 + 标志性冠饰 |
| `bone_weapon` | `98,102` | 前侧标志性武器（联动突进挥砍，并暴露 `getBoneWorldPos('bone_weapon')` 供特效接口绑定） |

## 3. 如何为角色接入专属 SVG 小人（零代码改动）

1. **约定优于配置**：直接将符合规范的文件保存为：
   ```text
   _packs/sprites/<角色id>.svg
   ```
   目前已内置 11 个核心与新角色专属 SVG（安诺琳、莱克、赫克、赫里斯、李凌、萨、祁铮、林秋、空白、阙鸣、沈砾）。
2. 后端 [battle_ui/match.py](../battle_ui/match.py) 会自动扫描 `_packs/sprites/` 并在状态快照 `character_sprites` 中下发 `/sprites/<角色id>.svg`，[battle_ui/__main__.py](../battle_ui/__main__.py) 提供带路径穿越防护的 `image/svg+xml` 静态服务。
3. **可选自定义路径**：如需指定自定义文件名，可在角色卡包 JSON 中添加 `"sprite_svg": "custom.svg"`（限定在 `_packs/sprites/` 目录内）。
4. **自动兜底**：未单独提供 `.svg` 文件的角色，前端自动调用 `buildParametricCharacterSvg` 生成完全同风格的 `160×160` 简洁几何棋子 5 骨骼 SVG，保证未来任意新角色开箱即用。
