# 特效接口与自然语言编写规范（《光点计划 III》）

战斗前端已解耦为数据驱动的 **FX 导演引擎**（[fx_director.js](../battle_ui/static/engine/fx_director.js) + [fx_compiler.py](../battle_ui/fx_compiler.py)）。角色创作者无需改动前端核心代码，可通过**自然语言**、**声明式 JSON DSL** 或**自定义 JS 脚本**三种方式为角色、技能、单颗骰子与被动设计专属视听演出。

---

## 1. 接入位置（约定优于配置，零冲突）

1. **独立特效包（推荐，不修改角色规则 JSON）**：
   在 `_packs/fx/<角色id>.json` 新建文件，后端自动加载、编译、校验并在快照 `character_fx` 中下发。
2. **内联写法（单文件卡包）**：
   也可在 `_packs/<角色>.json` 的角色、技能、骰子或被动上直接添加 `"fx"` 或 `"fx_prompt"` 字段，引擎会自动提取并与 `_packs/fx/<角色id>.json` 合并。
3. **自定义脚本插件**：
   在 `_packs/fx_scripts/<脚本名>.js` 编写 ES Module，并在特效配方中通过 `"script": "<脚本名>#<导出函数名>"` 引用；后端 `/fx_scripts/*.js` 自动安全托管。

---

## 2. 方式一：自然语言直接写特效（最省心）

在 `_packs/fx/<角色id>.json` 中直接写中文或英文描述字符串，系统会自动编译为完整的 3D 轨迹、粒子、镜头震动与 WebAudio 合成音效：

```json
{
  "color": "#1c946b",
  "defaults": {
    "slash": "翠绿疾速刀光挥斩，伴随清脆风鸣与金色散射粒子"
  },
  "skills": {
    "漂泊剑法": "翠绿双弧回旋风刃连斩，伴随清脆风鸣",
    "试音锤": "青铜重锤砸地激起三圈共鸣波纹，伴随低沉悠长青铜钟鸣"
  }
}
```

命令行实时预览编译结果或批量固化为标准 DSL：
```powershell
python3.12 -m battle_ui.fx_compiler --prompt "暗金细剑三连突刺破空，伴随金色火花与高频金属蜂鸣"
python3.12 -m battle_ui.fx_compiler --compile-pack _packs/fx/plan_b_annolin.json --write
```

## 3. 方式二：声明式 FX DSL（精确控制每帧演出）

### 事件挂载优先级（由具体到通用）
1. **单骰级**：`skills.<技能ID或名称>.dice.<"1"|"2"|"3">`
2. **技能级**：`skills.<技能ID或名称>.on_strike` / `on_clash_win`
3. **被动级**：`passives.<被动名>`
4. **角色默认级**：`defaults.slash` / `defaults.pierce` / `defaults.blunt` / `defaults.strike` / `defaults.passive` / `defaults["status:<状态名>"]`

### 空间锚点（直连 PR #1 SVG 骨骼）
`from` / `to` 可指定：`attacker.bone_weapon`、`attacker.bone_head`、`attacker.bone_torso`、`attacker.center`、`defender.center`、`clash.center`。

### 可用原子积木
| 字段 | 可选值 / 参数 | 说明 |
|---|---|---|
| `vfx[].primitive` | `slash_arc`, `pierce_lance`, `ground_shockwave`, `beam`, `shockwave_ring`, `ripple`, `sparks`, `shield_dome`, `block_barrier`, `shards`, `banner` | 3D/Shader/物理碎片/飘字视觉积木，支持 `color`、`count`、`delay_ms`、`stagger_ms`、`duration_ms`、`heavy` |
| `motion` | `lunge`, `recoil`, `evade`, `hitFlash`, `healGlow`, `passiveFlare` (`0..1.5`) | 角色物理姿态驱动 |
| `camera` | `shake` (`0..18`), `duration_ms` (`60..700`) | 镜头震动反馈 |
| `sfx` | 预设 `{"preset": "slash\|pierce\|blunt\|clash_heavy\|bell\|passive\|shield\|wind"}` 或合成配方 `{"waveform": "sine\|triangle\|sawtooth\|noise", "freq_start", "freq_end", "harmonics": [...], "duration_ms", "gain"}` | 纯 WebAudio 实时合成音效，无需音频文件 |

## 4. 方式三：代码级自定义特效脚本（`_packs/fx_scripts/*.js`）

```js
// _packs/fx_scripts/blank_prism_resonance.js
export function onPrismStrike(api, ctx) {
  const from = api.resolveAnchor('attacker.bone_weapon');
  const to = api.resolveAnchor('defender.center');
  api.three?.spawnEnergyBeam({ fromX: from.x, fromY: from.y - 16, toX: to.x, toY: to.y, colorHex: 0xead078, duration: 0.36 });
}
```
在 JSON 配方中添加 `"script": "blank_prism_resonance#onPrismStrike"` 即可挂载。脚本仅接收受控 `api`（`three`、`physics`、`audio`、`resolveAnchor`、`shake`、`floater`、`banner`、`motion`），且任何脚本异常都会被自动隔离，不影响主对战流程。
