## 一、核心原则（面向小手牌高算量博弈）

1. **必要信息零操作直出**
   - 《光点计划 III》手牌少（通常 3~5 张）但每张牌都是精确到字句的博弈工具。**手牌区、开牌前公开牌、统一开牌后的交锋牌、看顶选底、弃牌/战外牌堆、以及选人界面的角色技能组，全部直接展开为 100% 完整可读的实体卡面**，玩家无需悬停或点击即可一眼横向对比所有牌的费用、特性、骰子区间、伤害与完整原文。
   - 悬停仅作用于空间受限时（如 6+ 张手牌轻叠、超长 5 骰牌超出底边、或置卡期紧凑槽位）的顺滑抬起/1:1 聚焦，绝不靠悬停「解锁文字」。
2. **100% 原文保真（咬文嚼字红线）**
   - 严禁改写、概括、缩写或删减任何词条；
   - 严禁印刷 `Lv.X` 骰级标签，统一直接显示精确变动区间（如 `1~4`、`1~6`、`1~8`、`1~12`、`1~16`、`1~20`、`2+1~8`）；
   - 无附加词条的骰子保持留白，严禁输出「无附加词条」、风味文本或操作教学废话。
3. **减法美学与明亮日间色板（90% 纸墨 + 10% 精准功能色）**
   - 零黑（`max(R, G, B) >= 40`）、零蓝紫（`!(B > R + 15 && B > G + 15)`）。
   - **严禁套娃边框与高饱和整行彩底**：去掉多层嵌套圆角粗框与占位几何画窗，使用纯净温润纸白（`#fffdf8`）、极细发丝分割线（`#eae2d4`）与精准的 `3px` 左侧语义色条建立清晰的印刷级视觉层次。

## 二、统一骰子样式规范（Dice Grammar）

全界面所有骰子统一由 `DIE_STYLE`、`drawUnifiedDieFrame`、`buildDamageBadge`、`buildUnifiedDieRow` 渲染。

### 1. 六类骰型框型与色标
| 骰型 | 类别 | 框型 (`frame`) | 主色 | 极浅底色 |
| :--- | :--- | :--- | :--- | :--- |
| 斩击 (`slash`) | 进攻 | 菱形框 (`diamond`) | `#c93e2b` | `#fdf4f2` |
| 突刺 (`pierce`) | 进攻 | 菱形框 (`diamond`) | `#c27110` | `#fef8ec` |
| 砸击 (`blunt`) | 进攻 | 菱形框 (`diamond`) | `#a82f3e` | `#fcf2f4` |
| 招架 (`block`) | 防御 | 六角盾框 (`hex`) | `#177d6b` | `#f0f9f7` |
| 闪避 (`evade`) | 防御 | 圆形风环 (`circle`) | `#3b8c2c` | `#f3faf0` |
| 空白 (`blank`) | 空白 | 柔方框 (`square`) | `#8a7f71` | `#f6f2ea` |

### 2. 统一印刷式骰子行（去套娃边框）
- **纯净纸底 + 1px 发丝底线分割 + 左侧 3px 骰型色条**（仅当前正在结算的活跃骰铺暖金高亮 `#fdf5e2`）。
- **左列**：框型骰标 + 粗体数值区间（`FONT_NUM`）。
- **右列**：
  1. **独立伤害标（`DAMAGE_GRADE_STYLE`）**：若含独立伤害项（`2 点普通伤害` / `3 点穿甲伤害` / `3 点超穿甲伤害`），提炼为紧贴点数区间旁的轻量底纹 + 细底线 + 几何等级标（圆点=普通 `#c93e2b`、尖锥=穿甲 `#bf6c0e`、菱形=超穿甲 `#b02e57`），完整保留原文；
  2. **其余骰子词条**：直接紧随其后，经统一富文本引擎渲染 100% 原文。

## 三、统一技能卡样式规范（Skill Grammar）

全项目技能统一收口为唯一的印刷级实体卡 `buildFullCard`（另配横向目录条 `buildUnifiedSkillRow` 用于角色档案左侧目录）：

- **卡面基底**：温润纸白 `#fffdf8` + 极细 `1.15px` 外框 + 顶部 `3.2px` 语义色顶条（玩家一翠玉 `#1a825e` / 玩家二珊瑚朱 `#c8452e` / ≥4 费琥珀金 `#c98216`）。
- **卡头**：六面费用晶体（`drawCostCrystal`）+ 粗体技能名 + 归属/状态微标 + 1px 发丝底线。
- **卡身**：
  1. 特性微标行（`buildTraitPills`，仅存在特性时渲染）；
  2. 技能级词条板（`buildUnifiedEntryPlate` `variant='skill'`，仅存在时渲染）；
  3. 发丝分割的统一骰子行堆叠（`buildUnifiedDieRow`）。
- **手牌通栏布局**：手牌区横跨屏幕底部全宽（不再夹在左右边栏中间），3~5 张手牌每张 `226~272px` 宽直接并排完整展开，无需悬停即可同时通读整手牌。

## 四、统一词条排版与富文本高亮规范（Entry Grammar）

全界面被动、技能词条、骰子词条、状态说明与规则条目均经由 `buildRichVerbatimText` 与 `buildUnifiedEntryPlate` 统一渲染，**一字不改、零增删标点**：

1. **统一词条板（去粗边框）**：温润纸底 + 极细发丝外框 + 左侧 `3px` 语义色条（角色被动琥珀金 / 阵营被动阵营色 / 技能词条阵营色 / 状态说明状态专属色）。
2. **克制富文本高亮**：
   - **句首触发时机**（`使用时`/`使用后`/`拼点胜利时`/`命中时`/`命中前`/`暴击时`/`回合开始时`/`回合结束时` 等）：仅用极浅底纹 + `1.4px` 底部色线标出原字（摒弃厚重描边胶囊）；
   - **状态名（全部 19 种）**：按最长优先匹配并以 `STATUS_COLORS` 专属色加粗；
   - **护盾 / 伤害等级 / 远程词**：按对应 `SHIELD_STYLE` / `DAMAGE_GRADE_STYLE` / `TRAIT_STYLE` 专属色加粗；
   - **引用项与数值**：`「...」` 以深琥珀 `#9e5e0e` 加粗，符号数值与量词（`+1`、`×2`、`≥3`、`2 层`、`1 点`）以 `FONT_NUM` 深墨 `#2c241d` 加粗。
